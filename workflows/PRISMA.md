# PRISMA 2020 Workflow

## Identification
Search:
- Google Scholar
- IEEE Xplore
- ACM Digital Library
- Scopus
- Web of Science

Record:
- Query
- Date
- Database
- Result count

## Screening
Remove:
- Duplicates
- Irrelevant studies
- Non-research documents

## Eligibility
Assess:
- Quality
- Relevance
- Evidence strength
- Methodological fit

## Inclusion
Create final study set.

## Deliverables
- PRISMA flow diagram data
- Evidence matrix
- Exclusion reason log
