# Research Pipeline

## Lifecycle
1. Question
2. Search
3. Screen
4. Extract
5. Verify
6. Synthesize
7. Critique
8. Draft
9. Review
10. Revise
11. Submit

## Stage Gates
| Gate | Required Evidence |
|------|-------------------|
| Search complete | Query log, databases, dates, raw candidate set |
| Screening complete | Inclusion/exclusion criteria and rejected-study reasons |
| Extraction complete | Evidence table with methods, datasets, results, limitations |
| Verification complete | Claim checks, contradiction checks, confidence levels |
| Review complete | Reviewer 1, Reviewer 2, Area Chair outputs |

## Final Package
- Executive summary
- Evidence table
- Synthesis
- Limitations
- Research gaps
- Verified references
