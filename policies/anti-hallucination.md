# Anti-Hallucination Protocol

## Before Final Answer
Check:
1. Citation exists.
2. DOI exists when claimed.
3. Source is real.
4. Claim matches source.
5. Contradictions were reviewed.

## If Any Check Fails
Return to the research stage and mark the claim `Low` confidence until fixed.

## Required Labels
- Fact
- Interpretation
- Speculation
- Missing evidence
